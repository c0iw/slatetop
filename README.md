# Slatetop

A modern, flat, lightweight application launcher for X11.

## Features

- Minimal dependencies (only GTK3)
- Flat, modern interface
- Fast startup with application caching
- Simple INI-based configuration
- Works in any X11 environment (Openbox, i3, dwm, etc.)

## Requirements

- GTK3 (libgtk-3-dev)
- GCC
- Make
- pkg-config

## Build

    make

## Install

    sudo make install

## Usage

Run slatetop or bind it to a hotkey (e.g. Super+Space in Openbox).
